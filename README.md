# ganor.ng

Website for **Ganor**: find events, buy tickets and find trusted places near you.

Plain HTML, CSS and JavaScript. No framework and no runtime dependencies.

## Structure

```
src/                 Page sources (edit these)
  index.html
  docs.html, terms.html, privacy.html, refunds.html, credits.html  (generated by tools/pages.py)
  404.html
  partials/          head, header, footer
assets/
  css/fonts.css      Self-hosted brand fonts (Bricolage Grotesque, Inter)
  css/tokens.css     Brand tokens (colour, type, radius, motion)
  fonts/             Font files and their OFL licences
  css/site.css       Site styles
  js/site.js         Intro, reveals, demos, waitlist form
  brand/             Logo lockups, symbol, loader, wordmark
  icons/sprite.svg   Icon sprite (Solar, CC BY 4.0, see /credits)
  gate/              Gate check-in status graphics
  social/            Social icons (Feather and Tabler, MIT)
  img/               Pattern tile, share image (og.png)
tools/pages.py       Content for docs and legal pages; writes them into src/
tools/build.py       Builds src/ into the root HTML files
*.html (root)        Built output (committed, served as-is)
```

## Build

Requires Python 3 and the `qrcode` package (for the sample ticket QR).

```sh
pip install qrcode
python3 tools/pages.py   # only after editing docs/legal content
python3 tools/build.py
```

The build expands these tags in `src/*.html`:

| Tag | Does |
| --- | --- |
| `{{include:name}}` | Inserts `src/partials/name.html` |
| `{{sprite}}` | Inlines the icon sprite |
| `{{icon:name\|class}}` | An icon from the sprite |
| `{{svg:path\|class}}` | Inlines an SVG file |
| `{{qr:text}}` | A QR code SVG for the text |

Always edit `src/`, then rebuild. Don't edit the root HTML files by hand.

## Preview

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. To test on a phone, open `http://<your-computer-ip>:8080` on the same Wi-Fi.

The first-visit intro plays once per browser session. To see it again, open a new tab or clear `sessionStorage`.

## Waitlist

The form in `#join` posts JSON to the URL in its `data-endpoint` attribute:

```json
{ "role": "host", "name": "…", "phone": "…", "interest": "…", "source": "ganor.ng" }
```

With no endpoint set, it opens WhatsApp with the details filled in, so sign-ups still reach the team. To collect sign-ups in a sheet or form service, set `data-endpoint` on the `<form data-join>` in `src/index.html` and rebuild.

## Deploy (GitHub Pages)

1. Repo settings → Pages → Deploy from branch → `main`, folder `/ (root)`.
2. Custom domain: the `CNAME` file contains `ganor.ng`. In Pages settings, check the custom domain shows ganor.ng, then tick **Enforce HTTPS** once the certificate is issued.
3. The old preview address https://4hm4di.github.io/ganor/ now redirects to https://ganor.ng.
4. DNS at the registrar:
   - `A @` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME www` → `<github-username>.github.io`

## Content rules

- Fees, payout times and similar claims stay off the site until payments are final.
- Screens in the demos use sample data and are labelled as samples.
- Hausa copy only where it has been approved.

## Settings you may change

- **Fee:** `FEE_RATE` and `FEE_FLAT` at the top of `assets/js/site.js` drive the calculator and the hero checkout. Update the fee wording in `src/index.html` (pricing intro, FAQ) and `tools/pages.py` (docs, terms) to match.
- **Hero photo:** put a photo at `assets/img/hero.jpg` and set `data-photo="assets/img/hero.jpg"` on the hero `<section>` in `src/index.html`. The dark scrim is applied automatically.
- **Countdown:** `data-countdown` on the countdown in `src/index.html` (ISO date and time).

## Search and share previews

- `tools/seo.py` holds each page's title, description, canonical URL (always `https://ganor.ng/...`), share image and structured data. The build writes them into every page through `{{seo:slug}}`, and regenerates `sitemap.xml`.
- Share images (1200×630) live in `assets/img/og*.png`. Remake them after changing titles or icons:
  `pip install playwright && python3 -m playwright install chromium && python3 tools/og.py`
- The FAQ structured data is read from the FAQ on the page, so editing a question updates it automatically.
- Share previews and Google only see the real thing once ganor.ng points to this site (see Deploy). After that, check previews with the [Facebook sharing debugger](https://developers.facebook.com/tools/debug/) and submit `https://ganor.ng/sitemap.xml` in [Google Search Console](https://search.google.com/search-console).
