Refund policy

Refunds start with the host, because the host runs the event. Here’s how it works, and when we step in.

On this page

  • Ask the host first
  • If an event is cancelled
  • If an event changes
  • When to contact Ganor
  • How refunds are paid
  • Contact

Last updated 10 November 2026

{{icon:chat}}Ask the host first

Each event has its own refund rule, set by the host and shown on the event page before you pay. For any question about refunds, changes or the event itself, contact the host using the details on the event page.

{{icon:close-circle}}If an event is cancelled

If the host cancels the event, everyone who bought a ticket gets their money back, including the Ganor fee. The refund goes back the way you paid.

{{icon:calendar}}If an event changes

If the date, time or venue changes, we’ll message you on WhatsApp. If you can’t make the new date or place, ask the host for a refund under their event’s refund rule.

{{icon:info}}When to contact Ganor

Message us directly if:

  • You paid but your ticket didn’t arrive.
  • You were charged more than once for the same ticket.
  • An event was cancelled and you can’t reach the host.

We’ll look into it and, where a refund is owed, make sure it reaches you.

{{icon:wallet}}How refunds are paid

Refunds go back to the card or account you paid with, through our payment partner. Banks can take a few working days to show the money in your account.
