Refund policy

Refunds start with the host, because the host runs the event. Here’s how it works, and when we step in.

Last updated 14 November 2026

{{icon:chat}}Ask the host first

Each event is run by its host. For any question about refunds, changes or the event itself, contact the host on the WhatsApp or phone number shown on the event page.

{{icon:close-circle}}If an event is cancelled

If the host cancels a paid event, everyone who bought a ticket gets their money back, including the Ganor fee. The refund goes back the way you paid.

{{icon:calendar}}If an event changes

If the date, time or venue changes, the host should tell guests straight away, and the event page shows the new details. If you can’t make the new date or place, ask the host for a refund.

{{icon:receipt}}RSVP plan payments (hosts)

A paid RSVP plan covers one event. If you paid for a plan and haven’t published the event yet, message us and we’ll sort it out. Once the event is published, plan fees aren’t refundable, except where the law requires. If you paid twice for the same plan, we’ll refund the extra payment.

{{icon:info}}When to contact Ganor

Message us directly if:

  • You paid but your ticket didn’t appear.
  • You were charged more than once for the same ticket.
  • An event was cancelled and you can’t reach the host.

We’ll look into it and, where a refund is owed, make sure it reaches you.

{{icon:wallet}}How refunds are paid

Refunds go back to the card or account you paid with, through our payment partner. Banks can take a few working days to show the money in your account.
